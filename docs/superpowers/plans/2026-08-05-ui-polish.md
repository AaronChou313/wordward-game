> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement 7 gameplay/UI optimizations: equip-row layout split, gameplay help panel, shop item expansion + all-items pool, gem/soul-jade display, equip rarity sorting, best-record difficulty display, and dev-spec updates.

**Architecture:** Frontend is a Vite canvas game. Equip scene (`src/meta/equipScene.js`) rows become two-zone (text top, buttons bottom). A help panel is added to the home scene. Shop stock logic (`src/meta/shopStock.js`) changes from unowned-only to all-items pool with upgrade-on-purchase. Currency bars across scenes show gold+gems+soulJade. Equip sorting is a pure function in `src/config/equipment.js`. Best-record shows the highest-wave difficulty. Docs (`AGENTS.md`, `.agents/skills/wordward-development/SKILL.md`) get updated.

**Tech Stack:** Vite, vanilla JS, Canvas 2D, Vitest (frontend + worker).

- No D1 schema changes; no migrations.

```js
const RARITY_RANK = { epic: 3, rare: 2, fine: 1, common: 0 };

export function sortEquipOwned(list) {
  return (list || []).slice().sort((a, b) => {
    const r = (RARITY_RANK[b.rarity] ?? 0) - (RARITY_RANK[a.rarity] ?? 0);
    if (r !== 0) return r;
    const l = (b.lvl ?? 0) - (a.lvl ?? 0);
    if (l !== 0) return l;
    return (a.uid ?? 0) - (b.uid ?? 0);
  });
}
```

```js
export function rollShopStock(ownedIds, random = Math.random, count = 4) {
  const available = Object.keys(ITEMS).slice();
  for (let i = available.length - 1; i > 0; i--) {
    const roll = Math.max(0, Math.min(0.999999, Number(random()) || 0));
    const index = Math.floor(roll * (i + 1));
    [available[i], available[index]] = [available[index], available[i]];
  }
  return available.slice(0, Math.max(0, count));
}
```

- [ ] **Step 4: Change `buyShopStockItem` to upgrade owned items**

```js
import { ITEMS, upgradeCost } from '../config/items.js';

export function buyShopStockItem(save, id) {
  const item = ITEMS[id];
  if (!item || !save.shop || !save.shop.stock.includes(id)) {
    return { purchased: false, reason: 'stock' };
  }
  const currentLevel = save.items.owned[id] || 0;
  const cost = currentLevel >= 1 ? upgradeCost(id, currentLevel) : item.price;
  if (save.gold < cost) return { purchased: false, reason: 'gold' };

  save.gold -= cost;
  save.items.owned[id] = currentLevel + 1;
```

```js
import { availableDiffs } from '../config/difficulty.js';

export function bestRecordText(save) {
```
