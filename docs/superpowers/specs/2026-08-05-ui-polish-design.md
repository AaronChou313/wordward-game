# 玩法与 UI 优化设计：装备布局、玩法介绍、商城、货币显示、排序、纪录、开发规范

## 目标

对已在 preview 部署的三国文字塔防做 7 项玩法与 UI 优化：装备行布局、玩法介绍、商城道具扩充与集齐处理、宝石魂玉显示、装备排序、最高纪录显示、开发规范更新。所有改动在独立分支 `dev/ui-polish` 上分批提交，完成后推送由用户 PR 到 preview。

## 一、装备行布局优化

### 现状
`EquipScene` 装备行 `equipStatText(inst)`（词条文字，从 x=80 起）与洗练按钮（x=440-548）、升级按钮（x=560-680）重叠，长词条被按钮遮挡。

### 改动
- 装备行改为**上下分区**，行高 `ROW_H` 从 96 增至 ~130。
- **上区**（行顶 ~ 行顶+62）：装备名称 + 完整词条文字（`equipStatText`，含稀有度/Lv/词条），不裁剪。
- **下区**（行顶+66 ~ 行底）：三个按钮——`装备/卸下`（左侧）、`升 N宝`（中）、`洗 1魂`（右）。按钮水平排开，各自独立命中区。
- 列表可视区高度与 `maxScroll` 随行高同步更新。
- 按钮命中判定（`onPointerUp`）与渲染（`render`）都改为新布局。

### 测试
- `equipScene.test.js`：新增行高/按钮布局相关断言（词条文字绘制位置在上区，按钮命中区在下区，互不重叠）。

## 二、游戏玩法介绍

### 改动
- 主页（`HomeScene`）加 `？` 帮助按钮，打开全屏帮助面板。
- 帮助面板分节介绍：
  - **一、基本将士**：兵（近战，可驻守哨站）/骑（圆形范围，可驻守）/枪（直线穿透，可驻守）/弓（远程单体，可驻守）/炮（远程范围，可驻守）/增益字（放文字旁激活）。
  - **二、刷新与铲子**：5 格将士栏、刷新冷却、铲子激活格子、保底。
  - **三、军功与进阶**：30 波 Boss 军功、解锁难度/无尽、组词进阶。
  - **四、装备与货币**：金币/宝石/魂玉、装备强化/洗练/羁绊。
- 面板可滚动（复用背包/装备列表的 scroll + clip 模式）。

### 测试
- `homeScene` 相关测试：帮助按钮存在、打开面板、分节文字渲染、可滚动。

## 三、商城道具扩充 + 集齐后仍有内容

### 现状
`rollShopStock` 只从"未拥有道具"里刷；玩家集齐全部道具后 `available` 为空，商城永远空。

### 改动（双管齐下）
1. **新增 8 个道具**（`src/config/items.js`）：
   - 主动：冰霜符（全场减速）、雷击符（单体高伤）、治疗符（主公回血）、召唤符（立即召唤随机将士）。
   - 被动：锋刃旗（暴击率）、连弩旗（攻速）、粮草车（战斗金币）、铁壁旗（阻挡兵减伤）。
2. **商城刷新池从"未拥有"改为"全部道具"**：
   - `rollShopStock` 不再按 owned 过滤。
   - `buyShopStockItem` 对已拥有道具改为升级路径：消耗 `upgradeCost(id, curLevel)`，`owned[id]` 升 1 级。
   - 商城卡片显示已拥有状态（`已拥有 LvX`），购买后升级并更新已装备等级。

### 测试
- `shopStock.test.js`：刷新池含已拥有道具；购买已拥有道具升级而非报错。
- `items.test.js`：新增道具数量、类型、效果配置完整。
- `battle` 相关：新增主动道具效果（冰霜/雷击/治疗/召唤）可施放；新增被动道具 buff 生效。

## 五、装备按稀有度排序

### 改动
- `EquipScene.ownedOf()` 返回前排序：稀有度从高到低（传说>稀有>精良>普通），同稀有度按等级降序，同等级按 uid 升序（入库早者在前）。
- 排序逻辑放 `src/config/equipment.js`（纯函数 `sortEquipOwned(list)`），便于测试。

### 测试
- `equipment.test.js`：排序断言（传说>稀有>精良>普通、同稀有度等级降序、同等级 uid 升序）。

## 六、最高纪录显示难度+波数

### 现状
主页 `最高纪录：坚守 N 波`（`save.bestWave` 全局最高，不区分难度）。

### 改动
- 主页 `最高纪录` 遍历 `save.diff.best`（已解锁难度/无尽层），取波数最高者，显示 `最高纪录：{难度名} {波数} 波`。
- 无尽层显示 `无尽·N层 M 波`。
- 难度名从 `availableDiffs`/`endlessConfig` 取。

### 测试
- `homeScene` 相关测试：多难度纪录取最高波数对应难度；无尽层名正确。
