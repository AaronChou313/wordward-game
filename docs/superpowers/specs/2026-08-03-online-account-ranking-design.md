# 三国文字塔防：在线账号与排行榜设计

## 目标与技术栈

保留 Vite 前端，新增 Node.js API 与 PostgreSQL。首版支持用户名密码注册登录、个人资料、云端存档和按军功排序的全服排行榜，可部署到单台云服务器并为后续横向扩展保留边界。

## 服务端结构

API 使用 Fastify，数据库访问使用 Prisma，密码使用 Argon2id 哈希。短期访问令牌与可撤销刷新令牌配合；刷新令牌仅存于 `HttpOnly`、`Secure`、`SameSite=Lax` Cookie，访问令牌保存在内存中。所有输入使用 JSON Schema 校验，并设置登录限流。

核心表：

- `users`：ID、唯一用户名、密码哈希、状态、创建时间。
- `profiles`：昵称、头像 URL、简介、更新时间。
- `game_saves`：用户 ID、版本号、JSONB 存档、乐观锁版本、更新时间。
- `merit_claims`：用户、难度、Boss 波次、军功值，复合唯一键防止重复领取。
- `refresh_tokens`：令牌哈希、过期时间和撤销时间。

## API 与数据流

提供注册、登录、刷新、退出、读取/编辑个人资料、读取/写入存档、提交 Boss 击杀和读取排行榜接口。客户端登录后拉取云端存档；首次登录可选择上传本地存档或使用云端存档。后续写入携带存档版本，冲突时拒绝覆盖并要求重新拉取。

军功不接受客户端直接提交总数。客户端提交难度、Boss 波次和带局内随机种子的战斗摘要；服务端校验解锁顺序、波次和值，并以幂等记录累计军功。首版以规则校验和异常限流为主，不承诺完全防作弊；后续可增加服务端战斗回放验证。

## 排行榜与资料

排行榜按军功总数降序、首次达到该分数的时间升序排列，分页返回名次、昵称、头像和军功。个人资料允许昵称、头像 URL 和简介；用户名不可修改。头像首版只接受 HTTPS URL，暂不承担文件上传存储。

## 部署、安全与测试

使用 Docker Compose 运行 API 与 PostgreSQL，Nginx 提供 HTTPS、静态文件和 `/api` 反向代理。机密仅来自环境变量；数据库每日备份。测试包括服务层单元测试、API 集成测试、数据库唯一约束、认证失效、资料权限、存档冲突和排行榜排序。前端在 API 不可用时继续支持离线模式，并明确显示同步状态。
