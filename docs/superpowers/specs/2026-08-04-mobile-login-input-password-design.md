# 移动端登录输入与密码规则设计

## 目标

修复登录/注册页在移动端输入时画布随软键盘上移或缩放的问题，并将密码长度规则由 10–128 个字符调整为 1–128 个字符。

## 根因

`setupInput` 监听窗口 `resize` 并立即按 `window.innerHeight` 重算画布。移动端软键盘弹出会缩小可视视口并触发 `resize`，导致 750×1334 设计画布重新缩放和居中。隐藏原生输入框当前固定在视口底部，也可能触发浏览器为聚焦元素自动滚动。

## 设计

- 在原生隐藏输入框聚焦期间标记“文本输入活动中”。
- `setupInput` 在文本输入活动期间忽略仅由软键盘造成的 resize，保留键盘弹出前的画布尺寸和缩放。
- 隐藏输入框移动到视口顶部安全区域；聚焦前记录滚动位置，聚焦后恢复，降低浏览器自动滚动概率。
- 输入失焦后清除活动标记并主动触发一次布局刷新，适配键盘关闭后的真实视口。
- 前端登录/注册校验允许 1–128 字符密码。
- Worker `validateCredentials` 同步允许 1–128 字符，继续拒绝空密码和超过 128 字符的密码。
- 不修改 PBKDF2、D1 schema、现有用户密码记录或认证 token 行为。

## 测试

- 单元测试验证文本输入活动期间 resize 不改变画布布局，失焦后恢复响应。
- 单元测试验证输入控件使用顶部安全位置并管理活动状态。
- 前端账号测试验证单字符密码可提交，空密码仍被拒绝。
- Worker 安全测试验证 1 字符通过、空密码和 129 字符失败。
- 完成后运行 `npm run verify:worker`、production dry-run 和移动端视口手工检查。
